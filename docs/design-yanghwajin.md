## TL;DR
종이 크림 바탕(#FAF7F2) 위에 명조 800 헤드라인과 웜그레이 램프로 만든
**"기록관의 서가" 미학**. 화면 크기에 따라 곡률과 글자가 같이 자라는
clamp() 유동 시스템이 기술적 시그니처, 흑백 인물 사진과 오렌지 한 점(#FB6132)이
시각적 시그니처. 밀도는 낮고, 장식은 스크롤 리빌(AOS)뿐.

## 1. Visual identity

### 1.1 Surface description
차분함 · 문서적 · 따뜻한 미니멀 · 추모의 격식. 정보 밀도 낮음(한 화면 한 이야기).
독자층: 일반 방문자·유족·연구자 — 개발자용 밀도가 아니라 **읽는 사람의 보폭**.

### 1.2 Brand voice / Atmosphere
묘원(墓園)의 기록관이 가질 수 있는 유일한 목소리 — **종이의 침묵**. 화면은
디지털이지만 물성은 인쇄물이다: 크림 종이, 먹 글자, 명조의 세로 획. 죽은 이들의
이름을 다루므로 어떤 요소도 소리치지 않고, 색은 사진(과거)이 아니라 안내(현재)에만
허락된다. 그래서 인물 사진은 흑백으로 눕고, 산 자의 동선(버튼·링크)에만 오렌지가 켜진다.

### 1.3 The "ONE brand thing"
✅ **흑백 인물 초상 + 명조 이름표** — 모든 것을 회색으로 바꿔도 "인물의 삶을 모신
기록관"이 남는 장치. (차선 후보: clamp 유동 곡률 — 기술적으로는 이쪽이 더 희귀)

## 2. Design System (tokens)

### 2.1 Colors (실측 빈도순)
| 역할 | 값 | 신뢰도 |
|---|---|---|
| 먹글 | `#242424` | ✅ |
| 종이 크림(주 바탕) | `#FAF7F2` | ✅ |
| 백 패널 | `#FFF` / `#FAFAFA` | ✅ |
| 웜그레이 램프(모래·돌) | `#D1CEC7` → `#C3C2B2` → `#929286` → `#6A6762` | ✅ |
| 크림 워시(강조 배경) | `#FFF6E6` | ✅ |
| 액센트(한 점) | `#FB6132` 오렌지 | ✅ |
| 잔재 | `#2563EB`(Tailwind 기본 blue — 브랜드 아님) | ⚠️ |

### 2.2 Typography
- 페어링: **Nanum Myeongjo 400/700/800**(표제·이름) × **Pretendard**(본문·UI) ✅
- 스케일이 고정값이 아니라 **clamp() 유동**: 본문 `clamp(14px,1.05vw,18px)` ·
  중제 `clamp(16px,1.2vw,22px)` · 표제 `clamp(20px,1.5vw,24px)` ✅
- 고정값은 18/16/13px 세 단만. 굵기 천장: 명조 800.

### 2.3 Spacing
Tailwind 4px 그리드(유틸리티 기반). 섹션 사이 넉넉, 카드 안 촘촘. ⚠️(정확 수치 미검증)

### 2.4 Radii — 이 사이트의 기술 시그니처
- 알약 `9999px`(버튼·칩 다수) ✅
- 카드 `1rem`(16px) · `0.75rem`(12px) ✅
- **유동 곡률**: `clamp(10px,1.2vw,14px)` · `clamp(12px,1.4vw,18px)` ·
  `clamp(16px,2vw,9999px)` — 화면이 클수록 더 둥글어진다 ✅

### 2.5 Elevation / 장식
그림자 존재감 낮음(경계는 색 단차·헤어라인 위주). 장식 모션 = AOS 스크롤 리빌 +
Swiper 캐러셀. `backdrop-blur 12px` 사용처 있음(헤더 추정 ⚠️).

### 2.6 Borders
헤어라인 + 웜그레이. 두꺼운 테두리 없음.

### 2.7 Accessibility quick-check
`#242424`/`#FAF7F2` = 14.6:1 ✅ · `#6A6762`/`#FAF7F2` ≈ 5.4:1 ✅ ·
`#929286`/`#FAF7F2` ≈ 3.2:1 ⚠️(큰 글자 전용이어야) · `#FB6132`/백 ≈ 3.5:1 ⚠️(굵게/큰 글자 전용)

## 3. Components Inventory

### 3.1 Generic
- 버튼: 알약(9999px), 저채도 바탕 + 먹글, 호버에 오렌지 계열 ⚠️
- 카드: 백 패널 + 12~16px 곡률 + 얇은 경계
- 아이템 뷰어: 이미지가 크롬 없이 놓이고 **캡션·메타가 하단에 조용히**(우리 뷰어가 이미 차용)

### 3.2 Signature
- **인물 카드**: 흑백 누끼/사진 + 명조 이름 + 생몰년 — 전시 = 인물의 삶 구조
- **유동 곡률 카드**: 뷰포트 비례 radius (위 2.4)

## 4. Layout & Composition
- 한 화면 한 주제의 저밀도 세로 리듬, 중앙 정렬 히어로 + 명조 헤드라인
- text-xl/2xl 유틸 사용 빈도 낮음 = 타이포 위계를 clamp 커스텀이 담당
- 반응형: 유동 타이포·유동 곡률이 브레이크포인트 수를 줄이는 전략 ✅

## 5. Reconstruction notes
- 스택: 아무 정적 스택 + CSS clamp만으로 재현 가능. quick win = 유동 타이포/곡률.
- tricky: 흑백 사진의 품질 관리(원본 해상도), 오렌지 한 점의 절제(번지기 쉬움).

## 6. Do's & Don'ts
- ✅ 색은 동선에만, 과거(사진)는 무채로 · ✅ 이름은 언제나 명조 · ✅ 곡률·글자는 화면에 비례
- ❌ 오렌지를 본문·아이콘에 번지게 하지 말 것 · ❌ 그림자로 깊이 만들지 말 것(색 단차로)
- ❌ 밀도 높은 그리드(서가의 보폭이 무너짐)

## Open Questions
- 오렌지 `#FB6132`의 정확한 사용 반경(호버 전용인지 상시인지) — 정적 CSS로는 상태 매핑 불완전 ❓
- 간격 스케일의 실측 수치(스크린샷 미사용) ❓
- `backdrop-blur` 적용 대상 확정 ❓
